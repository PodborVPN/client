# Podbor

**Телега работает одной кнопкой, без ручного перебора серверов.**

Podbor — преднастроенный VPN-клиент для Android под реалии РФ. Вставляете ссылку на свою подписку (VLESS, Trojan, Shadowsocks) — и всё. Не грузится Телега или Инста — жмёте одну кнопку, Podbor сам находит в подписке сервер, через который сервис реально работает, и переключается на него.

> Своих серверов у Podbor нет — нужна ваша подписка.

## Чем отличается

- **Проверяет сервис, а не пинг.** Зелёный пинг не значит, что Телега работает. Podbor делает настоящее рукопожатие с Телегой и качает настоящий контент Инсты через каждый сервер.
- **Понимает, что творится с сетью.** Сначала меряет линию: открытая сеть, удушение, белые списки на мобильном — и подбирает серверы под текущий режим.
- **У каждого сервиса свой выход.** Телега и Инста подбираются отдельно и параллельно.
- **Объясняет словами**, почему не нашёл сервер, а не молча красит строчку красным.
- **Одна кнопка.** Без таблиц маршрутов, выбора ядра и сотни настроек — всё уже настроено.

## Приватность

- Без аккаунтов, телеметрии и рекламы.
- Подписка остаётся на телефоне.
- Локальные прокси-порты движка закрыты случайным паролем на каждый запуск — другие приложения на телефоне не могут ходить через ваши серверы.
- «Поделиться лентой» ничего не отправляет само: файл появляется только по нажатию, адреса серверов, ключи, имена и номера сот в нём заменены псевдонимами.

## Сборка

Нужны JDK 21, Android SDK (compileSdk 37), Go и `gomobile` для движка.

```sh
app/scripts/build-libxray.sh      # собирает app/libs/libXray.aar из XTLS/libXray (arm64)
./gradlew :app:assembleDebug
```

Тесты (JVM, телефон не нужен):

```sh
./gradlew :core:test :driver:test :app:testDebugUnitTest
```

Модули: `core` — чистые машины решений без ввода-вывода, `driver` — пробы, определитель режима линии, конфиг Xray и воспроизводимая лента, `app` — интерфейс Android и VPN-сервис.
